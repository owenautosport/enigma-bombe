German procedure: umlauts written out (Ä→AE), ß→SS, numbers spelled (2 = ZWO), X between words and for a full stop, CH often sent as Q.

These are radio intercepts as a Y-station operator would have logged them, with the header, the first group (the Kenngruppe, which says which key list is in use), then the cipher text in groups of five. Each one comes with what Hut 6 already knew about that station, which is where the crib comes from.

The first three are reconstructions, written in period style and encrypted on this page's Enigma using the German procedure of 1940–41. The last two are genuine wartime messages. Key sheets stay hidden until you ask for them.

How the procedure worked (1940 onward)

  1. Every unit on a network set up the same daily key at midnight from a printed key sheet: rotor order, ring settings, plugboard.
  2. For each message the operator picked a random Grundstellung (say HRB), set the rotor windows to it and typed a random message key (say NDH). The lamps gave the encrypted key (say UYE).
  3. He then set the windows to NDH and typed the message. The header sent "HRB UYE" in the clear.
  4. The receiver set HRB, typed UYE, read NDH off the lamps, set NDH and decrypted.

Pick a message and a crib, slide the crib into a position where no letter sits on itself, then choose which crib letters go into the menu. Each link in the menu gets its own drum stack (an Enigma with no plugboard), set ahead by that link's step. The stacks are cabled together according to the menu, a voltage goes onto one wire of the test letter's cable, and the test register shows which wires went live. Anything other than all 26 is a stop.

Recover the whole daily key

The Bombe can't find the left and middle ring settings, because they rarely affect a message. But the header gives the Grundstellung and the encrypted message key. The right daily key must turn one into the start windows you found, so try every left and middle ring and keep the ones that do.

Enigma wiring, notches and double-stepping follow the wartime machines. The Enigma was checked against the standard test (rotors I-II-III, reflector B, rings and windows at A: AAAAA → BDZGO), the double step (ADU → ADV AEW BFX) and three genuine wartime messages, each decrypted letter for letter from its published key: the Operation Barbarossa report (1941), the Dönitz succession signal (1945) and the U-534 "von Looks" signal. Rotor wirings match Crypto Museum's tables. The Bombe works the way the British machine did: offset scramblers, 26-wire cables, the diagonal board and a test register. Like the real machine, it assumes the middle rotor doesn't move during the menu.

The weather, daily and High Command intercepts are reconstructions written for this bench. The Barbarossa and Dönitz messages are genuine, with ciphertext exactly as published by the sources linked on their cards.
